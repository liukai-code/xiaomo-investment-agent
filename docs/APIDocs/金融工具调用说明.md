# 金融工具调用说明

> 更新时间：2026-06-28

本文档整理了金融投资导学 Agent 中所有金融相关 Tool 的调用方式、参数说明和使用场景。

---

## 一、金融数据工具（FinancialDataTool）

实时获取股票行情、基金净值等金融数据。

### 1.1 A股行情 — `getAShareQuote`

查询 A 股股票实时行情（数据源：腾讯财经接口）。

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `stockCode` | String | 6位股票代码 | `600519`（贵州茅台）、`000858`（五粮液） |

**返回内容：** 股票名称、当前价、涨跌额、涨跌幅、今开、昨收、最高、最低、成交量

**触发场景：**
- "茅台今天多少钱？"
- "五粮液涨了多少？"
- "600519行情"

**返回示例：**
```
A股行情 [贵州茅台 600519]
当前价: 1580.00
涨跌额: +12.50
涨跌幅: +0.80%
今开: 1570.00 | 昨收: 1567.50
最高: 1585.00 | 最低: 1565.00
成交量: 12345手
```

---

### 1.2 港股行情 — `getHKStockQuote`

查询港股股票实时行情。

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `stockCode` | String | 5位股票代码 | `00700`（腾讯）、`09988`（阿里巴巴） |

**触发场景：**
- "腾讯港股什么价？"
- "00700行情"

---

### 1.3 美股行情 — `getUSStockQuote`

查询美股股票实时行情。

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `stockCode` | String | 公司简称（大写） | `AAPL`（苹果）、`MSFT`（微软）、`TSLA`（特斯拉） |

**触发场景：**
- "苹果股价多少？"
- "特斯拉今天涨了吗？"

---

### 1.4 基金净值 — `getFundNav`

查询基金净值信息（数据源：天天基金）。

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `fundCode` | String | 6位基金代码 | `110011`（易方达中小盘）、`161725`（招商中证白酒） |

**返回内容：** 基金名称、最新净值、估算净值、估算涨幅

**触发场景：**
- "易方达蓝筹精选净值多少？"
- "161725今天涨了吗？"

**返回示例：**
```
基金净值 [易方达中小盘混合 110011]
最新净值: 3.2150（2026-06-27）
估算净值: 3.2200（2026-06-28 15:00）
估算涨幅: +0.16%
```

---

### 1.5 数据说明

- 行情数据来源于腾讯财经接口，**仅供参考**，可能存在延迟
- 基金净值数据来源于天天基金，盘中为估值，收盘后为实际净值
- 代码格式校验：仅允许数字和字母，最长10位

## 二、金融计算器工具（FinancialCalcTool）

提供精确的金融数学计算，所有金额计算使用 `BigDecimal` 保证精度。

### 2.1 基础利息

#### `compoundInterest` — 复利终值

| 参数 | 类型 | 说明 |
|------|------|------|
| `principal` | double | 本金（元） |
| `annualRate` | double | 年化利率（如 0.05 表示 5%） |
| `years` | int | 投资年限 |

**公式：** 终值 = 本金 × (1 + 利率)^年数

**示例：** "10万元年化5%存5年有多少？"

---

#### `simpleInterest` — 单利终值

| 参数 | 类型 | 说明 |
|------|------|------|
| `principal` | double | 本金（元） |
| `annualRate` | double | 年化利率 |
| `years` | int | 投资年限 |

**公式：** 终值 = 本金 × (1 + 利率 × 年数)

---

#### `annualizedReturn` — 年化收益率换算

| 参数 | 类型 | 说明 |
|------|------|------|
| `totalReturnPercent` | double | 总收益率百分比（如 8 表示 8%） |
| `days` | int | 持有天数 |

**公式：** 年化收益率 = (1 + 总收益率)^(365/天数) - 1

**示例：** "3个月赚了8%，年化是多少？"

---

#### `dcaReturn` — 定投收益（月定投）

| 参数 | 类型 | 说明 |
|------|------|------|
| `monthlyAmount` | double | 每月定投金额（元） |
| `annualRate` | double | 年化收益率 |
| `months` | int | 定投月数 |

**公式：** FV = PMT × [((1+r)^n - 1) / r] × (1+r)，其中 r = 年利率/12

**示例：** "每月定投2000，年化8%，3年后有多少？"

---

#### `compoundDca` — 复利+定投综合计算

支持初始资金 + 日/周/月定投 + 复利的综合场景。

| 参数 | 类型 | 说明 |
|------|------|------|
| `initialCapital` | double | 初始资金（元） |
| `periodicAmount` | double | 每期定投金额（元） |
| `annualRate` | double | 年化收益率 |
| `years` | int | 投资年限 |
| `frequency` | String | 定投频率：`daily` / `weekly` / `monthly` |

**示例：** "初始资金7890元，每日定投50元，年化7.8%，20年后多少？"

**返回内容：** 初始资金复利终值、定投终值、总投入、总终值、总收益（分项+合计）

---

#### `ruleOf72` — 72法则

| 参数 | 类型 | 说明 |
|------|------|------|
| `annualRate` | double | 年化收益率 |

**公式：** 翻倍年数 ≈ 72 / (利率×100)

**示例：** "年化6%多久翻倍？" → 约12年

---

### 2.2 估值指标

#### `peRatio` — 市盈率

| 参数 | 类型 | 说明 |
|------|------|------|
| `stockPrice` | double | 股价（元） |
| `earningsPerShare` | double | 每股收益（元） |

**公式：** PE = 股价 / 每股收益

**估值区间参考：** <15 低估 | 15-25 合理 | 25-40 偏高 | >40 高估

---

#### `pbRatio` — 市净率

| 参数 | 类型 | 说明 |
|------|------|------|
| `stockPrice` | double | 股价（元） |
| `bookValuePerShare` | double | 每股净资产（元） |

**公式：** PB = 股价 / 每股净资产

**参考：** <1 破净 | 1-2 较低 | 2-5 适中 | >5 较高

---

#### `dividendYield` — 股息率

| 参数 | 类型 | 说明 |
|------|------|------|
| `annualDividend` | double | 年度每股分红（元） |
| `stockPrice` | double | 股价（元） |

**公式：** 股息率 = 年度分红 / 股价 × 100%

---

### 2.3 贷款

#### `loanPayment` — 等额本息月供

| 参数 | 类型 | 说明 |
|------|------|------|
| `principal` | double | 贷款本金（元） |
| `annualRate` | double | 年利率（如 0.041 表示 4.1%） |
| `months` | int | 还款总月数（30年=360月） |

**公式：** 月供 = P × r × (1+r)^n / ((1+r)^n - 1)，其中 r = 年利率/12

**返回内容：** 月供、总还款、总利息、利息占比

**示例：** "贷款100万，利率4.1%，30年月供多少？"

---

### 2.4 投资决策

#### `npv` — 净现值

| 参数 | 类型 | 说明 |
|------|------|------|
| `discountRate` | double | 折现率（如 0.1 表示 10%） |
| `cashFlows` | String | 现金流数组，逗号分隔，第一个通常为负数 |

**公式：** NPV = Σ CF_i / (1+r)^i

**结论：** NPV > 0 值得投资 | NPV = 0 盈亏平衡 | NPV < 0 不值得投资

**示例：** "投入1万，之后4年分别收回3000、4000、5000、6000，折现率10%，值得投吗？"

---

#### `irr` — 内部收益率

| 参数 | 类型 | 说明 |
|------|------|------|
| `cashFlows` | String | 现金流数组，逗号分隔 |

**算法：** 牛顿迭代法求使 NPV=0 的折现率

**示例：** "投入1万，分4年收回3000、4000、5000、6000，收益率多少？" → 约 24.89%

---

### 2.5 债券

#### `bondPrice` — 债券定价

| 参数 | 类型 | 说明 |
|------|------|------|
| `faceValue` | double | 债券面值（元） |
| `couponRate` | double | 票面利率 |
| `marketRate` | double | 市场利率/到期收益率 |
| `periods` | int | 剩余付息期数（年） |

**公式：** 价格 = 票息年金现值 + 面值现值

**结论：** 票面利率 > 市场利率 → 溢价 | 票面利率 < 市场利率 → 折价 | 相等 → 平价

---

#### `bondYtm` — 债券到期收益率

| 参数 | 类型 | 说明 |
|------|------|------|
| `faceValue` | double | 债券面值（元） |
| `marketPrice` | double | 当前市场价格（元） |
| `couponRate` | double | 票面利率 |
| `periods` | int | 剩余付息期数（年） |

**算法：** 牛顿迭代法求 YTM

---

### 2.6 退休规划

#### `retirementTarget` — 退休所需本金

| 参数 | 类型 | 说明 |
|------|------|------|
| `annualExpense` | double | 退休后每年支出（元） |
| `safeWithdrawalRate` | Double | 安全提取率（默认 0.04 即 4%，可选） |

**公式：** 所需本金 = 年支出 / 提取率

**示例：** "年支出20万，需要存多少钱退休？" → 500万（4%法则）

---

#### `withdrawalPlan` — 定额提取计划

| 参数 | 类型 | 说明 |
|------|------|------|
| `principal` | double | 初始本金（元） |
| `annualWithdrawal` | double | 每年提取金额（元） |
| `annualRate` | double | 预期年化收益率 |

**返回内容：** 本金可持续年数、逐年明细（前10年+最后一年）

---

### 2.7 风险指标

#### `sharpeRatio` — 夏普比率

| 参数 | 类型 | 说明 |
|------|------|------|
| `portfolioReturn` | double | 投资组合年化收益率 |
| `riskFreeRate` | double | 无风险收益率 |
| `volatility` | double | 年化波动率/标准差 |

**公式：** 夏普比率 = (组合收益 - 无风险收益) / 波动率

**参考：** <0 不推荐 | 0-1 一般 | 1-2 良好 | 2-3 优秀 | >3 极佳

---

#### `maxDrawdown` — 最大回撤

| 参数 | 类型 | 说明 |
|------|------|------|
| `navSeries` | String | 净值/价格序列，逗号分隔 |

**示例：** "最大回撤是多少？" → 输入 `"1.0,1.2,0.9,1.1,0.8,1.0"` → 33.33%

---

### 2.8 收益分析

#### `cagr` — 复合年增长率

| 参数 | 类型 | 说明 |
|------|------|------|
| `beginValue` | double | 期初价值（元） |
| `endValue` | double | 期末价值（元） |
| `years` | int | 投资年数 |

**公式：** CAGR = (终值/初值)^(1/年数) - 1

---

#### `totalReturn` — 总收益率（含分红）

| 参数 | 类型 | 说明 |
|------|------|------|
| `buyPrice` | double | 买入价（元） |
| `sellPrice` | double | 卖出价（元） |
| `dividends` | double | 期间累计分红（元），无分红填 0 |

**公式：** 总收益率 = (卖出价 + 分红 - 买入价) / 买入价 × 100%

---

#### `inflationAdjusted` — 通胀调整

| 参数 | 类型 | 说明 |
|------|------|------|
| `amount` | double | 当前金额（元） |
| `inflationRate` | double | 年通胀率 |
| `years` | int | 年数 |

**公式：** 实际购买力 = 金额 × (1 - 通胀率)^年数

**示例：** "100万按3%通胀，10年后相当于今天多少？" → 约 73.7 万

---

### 2.9 通用计算

#### `calculate` — 数学表达式计算

当 LLM 需要先做一步数学运算时调用，支持 `+` `-` `*` `/` 和括号。

| 参数 | 类型 | 说明 |
|------|------|------|
| `expression` | String | 数学表达式 |

**示例：** `calculate("50*365")` → 18250

## 三、LLM 调用规范

System Prompt 中的关键规则：

1. **金融计算必须调用工具**，不要自己算
2. **日定投或有初始资金**时用 `compoundDca`，月定投用 `dcaReturn`
3. 查询金融数据时需注明**数据可能有延迟，仅供参考**
4. 涉及具体投资时提示**"投资有风险，入市需谨慎"**
